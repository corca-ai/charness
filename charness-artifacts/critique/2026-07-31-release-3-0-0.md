# Release 3 0 0

Date: 2026-07-31

## Decision Under Review

Publish `charness` 3.0.0 (tag `v3.0.0`) from `main`, covering the 47 commits
since `v2.12.0`. The bump was raised from the maintainer's initial `minor` to
`major` during this critique, on evidence the review produced. Publication is an
irreversible boundary: tag push and a public GitHub release.

## Failure Angles

- **A bump that under-signals a break.** The delta adds refusals, and a
  consumer's green can turn nonzero with no edit on their side.
- **Auto-generated notes.** This repo pushes straight to `main`; GitHub's
  `--generate-notes` builds from merged PRs, so 47 commits can publish as a
  single changelog link. The repo's own post-publish arm records five releases
  that escaped exactly this way, and it is advisory and after the fact.
- **A ledger that outruns its channel.** The release artifact asserts push
  completion, drift scope, and "verified" through the same `gh` binary that
  created the release.
- **Stale evidence riding a release.** The standing quality artifact predates
  the whole delta.
- **A release surface publishing its own known holes.** The publisher itself
  carries open sweep rows.

## Counterweight Pass

- **Real blockers, fixed before the tag:** the bump level (evidence below); the
  missing notes file, drafted rather than left to `--generate-notes`; the gate
  module docstring that shipped a two-exit-code contract while the code has
  three.
- **Withdrawn rather than shipped:** nothing. No delta content was reverted for
  this release.
- **Over-worry:** that the delegated-review floor's English vocabulary blocks
  non-English consumers outright. It does not — the cited-record arm is
  language-neutral — but the notes state the constraint rather than leaving the
  consumer to discover it.
- **Accepted and recorded, not closed:** the ledger-honesty defects (F5, F6,
  F7), the release-publisher sweep rows, and the stale quality artifact. They
  are follow-up slices on the release surface, not reasons to hold a release
  that mostly closes measured fail-opens.

## Non-Claims

- **No consuming repo was exercised against any new floor in this release.**
  Every measurement is against this repo's own corpus.
- The bump decision rests on one verified behavior change (exit 0 to exit 3). No
  claim that a real consumer is currently pinning `--head-sha`; the claim is
  that the documented-natural config now fails.
- The release ledger's "verified" wording is not independent verification: the
  HTTP probe is credential-distinct but shares the publisher's host and process,
  and it establishes only that the tag page is reachable and names the tag.
- F4, F5, F6, F9, and F10 are recorded and shipped, not repaired.
- Boundary fingerprints were snapshotted before the review round and `verify`
  returned `ok: true` with every drift parent-attributed; both reviewers were
  read-only by their own report.
- This critique was written before publication. Whether the publish succeeded,
  and what the public surface actually shows, is the release artifact's claim,
  not this one's.
