# V6 0 0 Release Critique
Date: 2026-08-14

## Decision Under Review

Publish charness 6.0.0 from `origin/main` `0a1a53405`, a major release whose
breaking surface is a removed public flag, two release-probe payload changes, and
six shell gates that now refuse to run from an exported copy.

## Failure Angles

- The notes are the operator-facing artifact and were authored by the same agent
  that wrote the code, on a day when four of its published claims were already
  proven false by review.
- A MAJOR part can be right for the wrong reasons: breaking changes filed under
  "Added capability" are invisible to a reader scanning the breaking section.
- Known-weak surfaces disclosed during development can be quietly dropped from
  the record between development and publication.
- The prepared-stop record's wording changed in this release, so a claims
  reviewer comparing records sees an apparent regression that is actually the
  repaired honesty.

## Counterweight Pass

- The CODE in range is sound; the bounded reviewer found no shipping defect that
  blocks, and every behavioral claim about the probes, the shell gates, the
  retro floor and the adapter refusal verified true.
- MAJOR is not merely right, it is under-justified: three further breaking
  classes were filed as additions.
- The `--close-issue-carrier-file` sentinel gap reads worse than it is — the
  carrier body is not rendered into the release record, so the hole the check
  closes is not reachable through that flag today.
- The `blocked`-on-setup-failure classification errs fail-closed: it can stop a
  release it should not, never ship one it should not.
