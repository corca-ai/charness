# Critique Review — Release 0.60.0

## Decision Under Review

**0.59.0 → 0.60.0 (MINOR).** Headline consumer-visible change: charness `gather`
is now public-source only — the credentialed `gather-slack`/`gather-notion`
runtimes (incl. raw `SLACK_BOT_TOKEN`) are deleted and `slack`/`notion` are no
longer valid `gather_provider` sources (#418). Bundles a deterministic `achieve`
early-close reader-surfacing fix.

## Release Scope

- Version: 0.59.0 → 0.60.0, tag `v0.60.0`, MINOR bump (rationale below).
- Commits: `efb77c9b` (#418 gather public-only removal), `591c1652` (achieve
  early-close surfacing), plus release prep (notes, `.gitignore` cleanup,
  doc reconcile, this artifact).
- For consumers: **breaking** — a `.agents/gather-adapter.yaml` declaring
  `gather_provider.slack`/`notion` now resolves `valid=False`. Migration carried
  in `charness-artifacts/release/v0.60.0-notes.md`.

## Surface-Lock Inventory

- Generated: `packaging/charness.json` (3 version fields), both plugin manifests,
  the `plugins/charness/` mirror — all `0.59.0`, bumped consistently by sync.
- Consumer-visible behavior: gather source set `slack`/`notion` removed (hard
  reject); `google_workspace` default `direct-cli` → `none`.
- Removed surfaces: `skills/support/gather-slack`, `skills/support/gather-notion`,
  `skills/public/gather/scripts/advise_slack_path.py`, gather-{slack,notion} locks.
- New guard: `tests/quality_gates/test_provider_boundary.py`.

## Failure Angles

- **Weinberg (bump/layer):** version-policy.md flags this MAJOR (removed install
  surface + broken automation + forced migration). Countered by 0.x pre-1.0
  convention + explicit override rationale in the notes (see F-BUMP).
- **Minto (communication):** v0.59.0 told operators to adopt a `gather_provider`
  config this release rejects; the migration must be loud (F-MIGRATE).
- **Gawande (operational):** mirror re-sync during bump could reintroduce a
  removed marker; the provider-boundary gate + full suite run post-sync catch it.
- **Raskin (humane):** a rejected adapter is a hard stop, but the error names the
  allowed sources, and the notes give the exact edit — honest, not a dead end.

## Counterweight Pass

Real blockers were the migration notes and the bump-level judgment (both
resolved before ship). The MAJOR-vs-MINOR call is genuine but low-regret as
MINOR: `v0.60.0` does not preclude a later intentional `1.0.0`, whereas spending
`1.0.0` here would prematurely signal API stability. The achieve slice is
byte-identical on goal acceptance — safe to bundle.
