- Minto / communication: whether the drafted notes match what the code range changes. The reviewer found two advisories: the debug routing sentence blurred unresolved, unknown, and malformed cases, and the Node mutation-reporter note needed a focused repro. Both are carried into the notes.
- Raskin / interface: whether operator-facing wording or behavior regresses. No regression was found; the only operator-facing change is the lane stop rule, which the notes describe.
- Single-reviewer exception: one reviewer covered three separately evidenced angles because the release is a patch of four small units that each had their own fresh-eye review before merge, and a second reviewer would re-read the same bytes. An earlier attempt (`release-8148-candidate`) returned `defer` only because its lens asked for version and claims surfaces that do not exist before the publish helper runs; it found no code-level blocker. The lens was narrowed to code and drafted notes, with version, manifest, and claims judged by the later claims review, and the notes were bound as an input. That change of input is why the second attempt is recorded as a first attempt for its own identity.
