# release-6-2-0
Date: 2026-08-18

## Decision Under Review

Cutting charness 6.2.0 from `main`, covering `c34155a48..a9df79fe6`: the artifact
line budget became a consuming repo's adapter setting (#640), plus the shared
`optional_int` primitive that made it possible.

## Failure Angles

- Bump level: three new adapter fields and two new `scripts/` modules read as
  additive, but a removed name, a changed default, or a payload shape someone
  parses positionally would make `minor` a lie.
- Silent upgrade change: a consumer who sets nothing must see byte-identical
  behavior. A moved default would be the worst possible failure of this feature.
- The consumer-facing addition itself: the scaffold hint now fires in installed
  layouts where it previously did not. A hint naming an unrunnable command is
  worse than the nothing it replaced.
- Mixed-version installs: this range added a second parameter to a shipped
  checker and reads a field name off a resolver loaded from a separate tree.
- Disclosure: the range was pushed past a red runtime-budget gate.

## Counterweight Pass

- Blockers, repaired before the cut: the installed hint emitted a plugin-root
  relative path the consumer's cwd cannot resolve; `_skill_id_from_scaffold`
  anchored positionally and lost the skill name for that same reader; and
  `check_doc_authoring_preflight` could raise an uncaught `TypeError` against an
  older vendored validator. All three were introduced by this range.
- Over-worry, closed by measurement rather than argument: the three shipped
  defaults are byte-identical to `c34155a48` (78/180/140), so the zero-config
  upgrade path is unchanged and `minor` holds.
- Real but not blocking: `NEAR_LIMIT_LINES` was removed from `plan_handoff_run` —
  a module constant of a CLI-invoked script, with no in-tree importer.
- Real and disclosed rather than fixed: a handoff adapter with an unsupported
  `version` drops `max_content_lines` via the shared loader's early return, while
  debug honors `max_artifact_lines` in the same situation. Changing that early
  return is a behavior change for nine skills and does not belong in a release cut.
- The runtime-budget bar was red and orthogonal (measured A/B, isolated: base
  87.4s vs head 85.8s) and is filed as #668. This bullet said "not a third number"
  when it was written, which the release then made false, and a claims round caught
  the artifact contradicting the tree it vouched for. What actually happened: the
  trigger's named work was DONE — profiling found a flat tail with no hotspot, and
  sixteen real-corpus probes moved to a `slow_corpus` lane, taking the standing lane
  from 85.8s to 75.6s isolated — and was MEASURED not to move the bar. In-gate
  samples after the cut read 128196, 126939, 135892, median 126645 -> 125850. The
  label is contention-bound, not suite-bound. On that refutation, a different reason
  from the one the trigger forbade repeating, the bar was releveled 120000 -> 155000
  with the reasoning written beside the number.
