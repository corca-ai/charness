Date: 2026-07-29

## Decision Under Review

Publishing charness 2.12.0 (minor, from 2.11.3) over `214a1561..HEAD`. The range
closes two escapes at the two places this harness renders a verdict — the release
publish boundary and the quality runner's own summary line — and re-bases a runtime
budget that had contradicted an armed lane since the session before this one.

## Failure Angles

- **The bump level launders a break.** A refusal that stops a publish which
  previously succeeded is an invocation-contract change; calling it minor because
  the intent was additive is deciding from intent rather than from what a consuming
  repo experiences.
- **The notes carry the class the release fixes.** A release note that claims more
  than the code establishes is the same defect as a gate printing PASS over a scope
  it never read, in the surface operators actually read.
- **The fix's own wiring reproduces the escape.** A refusal keyed on something a
  consumer can silently fail to set is a green over an unestablished scope.
- **A budget raised to make a red light green.** The aggregate moved from 62000 to
  420000 in this range; if the bar was not genuinely stale, that is exactly the
  loosening this repo refuses.

## Counterweight Pass

- Not over-worry on the bump: the affected publish shape is a mis-publish the
  release intends to stop, and recovery is one existing flag with no rename,
  removal, or data migration. `minor` holds — but the reasoning belongs in the
  notes, which is what the repo's version policy requires and what the first draft
  omitted.
- The budget raise is defensible and was checked against the alternative: the prior
  bar was 62000 while the observed median was 182923ms, so it had been failing on a
  stale basis; and `--suggest-budgets` proposed 769000, which was REFUSED because it
  was 1.4x an outlier produced by a six-commit unpushed range. The bar is 420000 and
  the observed 549239ms run would still trip it.
- Not shipped: nothing in this range weakens a gate without an in-file justification.
