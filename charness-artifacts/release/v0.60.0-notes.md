# charness v0.60.0

## Scope

One consumer-visible **breaking** change — **charness `gather` is now
public-source only; the credentialed Slack/Notion gather providers are removed**
(#418) — plus a deterministic `achieve` early-close reader-surfacing fix. No
operator-typed command, flag, doctor output, or install step changed.

## Breaking change — read this if you use `gather` for Slack or Notion

charness `gather` no longer reaches credentialed organizational data. The
charness-owned Slack/Notion gather runtimes (`gather-slack`, `gather-notion`,
including their raw `SLACK_BOT_TOKEN` route) are **deleted**, and `slack`/`notion`
are **no longer valid `gather_provider` sources**.

This completes #417's direction: gather is public-source only, and credentialed
org data (Slack, Notion, private Google Workspace, Drive) is the consuming
runtime's responsibility, reached through its own capability/connector surface —
never a charness-held token. It removes the non-portable provider wording that a
downstream consumer (e.g. Ceal) otherwise had to quarantine (#418).

**Migration — required if your `.agents/gather-adapter.yaml` declares `slack` or
`notion`:** those keys now make the adapter **invalid** (`gather_provider.slack
is not a known source; allowed: ['github', 'google_workspace']`). Remove them:

```yaml
# BEFORE (now rejected)
gather_provider:
  slack:
    mode: direct-cli
  notion:
    mode: host-mediated

# AFTER — gather only models public-source providers
gather_provider:
  github:
    mode: direct-cli        # public GitHub content via gh (dev tooling)
  google_workspace:
    mode: none              # host-mediated/export/browser for private content
```

To keep reaching Slack/Notion, route that access through your runtime's own
capability/connector (the same host-mediated capability contract charness already
uses), not through charness gather.

`github` still defaults to `direct-cli` (public content via `gh`, no org token).
`google_workspace` now defaults to `none` (was `direct-cli`) — its private content
routes to a host-mediated capability, an operator export, or a browser fallback.
Credentialless public and local gather is unaffected.

## Changes

- **gather public-source only (#418).** Deleted the `gather-slack`/`gather-notion`
  support skills and the `advise_slack_path.py` adviser; `resolve_adapter` now
  models only `github`+`google_workspace` and rejects `slack`/`notion`; every
  model-facing gather surface + governing doc rewritten to the public-only
  boundary; the plugin bundle no longer ships the credentialed surface.
- **Provider-boundary gate.** New deterministic gate
  (`tests/quality_gates/test_provider_boundary.py`) scans all consumer-materialized
  surfaces (skills/, the plugins mirror, integrations, the `charness` CLI) for the
  removed credentialed routes and scans model-facing skill guidance for a generic
  org bot/api-token pattern, with fixture coverage — so the boundary cannot
  silently regress.
- **achieve early-close surfacing.** A goal early-close floor's refusal (a
  PRESENT+BOUND report with a hollow section) is now surfaced where the author
  reads instead of forcing a discover-by-failing loop. Deterministic reader-only
  change; goal-artifact acceptance is byte-identical.

## Bump rationale (MINOR, not MAJOR)

Per `version-policy.md` this change hits MAJOR triggers (a removed install
surface + an adapter config charness itself told operators to adopt in v0.59.0
now hard-fails), so the bump is a deliberate judgment call, not a default: it
ships as **MINOR (0.59.0 → 0.60.0)** under pre-1.0 (0.x) convention, where a
minor may carry a breaking change, and because the removed surface was an
operator-declared deprecated/"dangerous" credentialed route. The forced-migration
step is carried explicitly in the breaking-change section above. Reserving the
`1.0.0` MAJOR for an intentional stability milestone rather than spending it here.

## Install

- Run `charness update` to install v0.60.0, then `charness doctor` to confirm no
  version skew.
- If you use Slack/Notion `gather`, apply the migration above before upgrading.

## Toward

  public-only; credentialed org data host/runtime-owned). Verified by the new
