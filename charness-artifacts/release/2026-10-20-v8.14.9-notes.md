# Charness v8.14.9

## What changed

- Mutation test plans whose test command runs `node --test` directly now get the TAP reporter by default, so the mutation baseline reader can parse the output under Node `v24.14.1`, where a plain `node --test` produced the `spec` reporter. This repairs the Known issue recorded in the v8.14.8 notes for this repository's own quality lane; a plan that reaches Node through a wrapper such as `npm test` has to select the TAP reporter itself.
- A test covers a Node test command that is left unchanged because it has no `--test` option before `--`.
- The `quality-core` CI workflow runs the mutation reporter tests on Node `22` and Node `24`, so a reporter regression on those Node majors is caught in CI; a later Node major is not covered until the matrix is edited.

## Update

Run `charness update`, then use `charness version` to read back the installed version. No migration is required. The Node `PATH` workaround from the v8.14.8 notes is no longer needed for this repository's quality lane.
