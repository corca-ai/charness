# Charness v1.0.7

## Fixed

- Claude plugin installs now package the bounded reviewer envelope at
  `agents/bounded-reviewer.md`.
- The reviewer-boundary fingerprint command resolves its helper from the active
  installed skill directory instead of a consuming repository's missing
  `skills/shared/` tree.
- Codex reviewer guidance now uses the native `explorer` path with the bounded
  review packet; it does not claim Codex loads Claude's markdown envelope.

## Update

Run `charness update`, then restart active Claude Code and Codex sessions
before judging the refreshed plugin behavior.

## Verification Boundary

The parent-side fingerprint remains the portable enforcement rail. Claude
envelope binding and Codex reviewer-tier application are host-specific and are
not claimed as live behavior by this release.
