# Release notes: v8.1.0-notes

## Summary

A minor release: the docs budget and the lesson lifecycle readback are new
maintained behaviour an operator adopts without migration, so the lightest
honest bump is minor, and the operator named this version. No public skill,
`charness` subcommand, shell gate, or install surface gained or lost a member:
the item lists in the derived block below are identical, as sets, to the same
lists in the v8.0.3 notes' derived block, and the release adapter's
`required_release_surfaces` is byte-identical to its v8.0.3 version. The
update path is the same `charness update` fast-forward as before; no persisted
format an installed consumer reads was changed.

**A docs page has a word budget.** `scripts/gates/check_docs_length.py` holds
every `docs/` page to a fixed gate-measured word budget with a shrink-only
record of the pages already over it, and runs as a component of
`scripts/check-docs.sh`. Fenced code is not counted. A consuming repo that
runs the shipped `check-docs.sh` gets the component; a page over budget that
is not in the record is refused, and a recorded page may only shrink. The
`docs/` pages in this tree were cut under that rule to state current facts and
link their owners, with the removed narratives moved to dated artifacts.

**A graduated lesson is watched by its own tag.** A lesson lifecycle event
now records the retros that tagged its class when it was settled, and
`scripts/lessons/check_lesson_ledger.py` prints an advisory naming any
graduated lesson a later retro tags again. That line is the readback that the
owning page held; what to do about it is settled the same way the graduation
was. The shared lesson-graduation reference says so, and the retro skill's
ledger bullet states that the agent authors each score event from a cited
session action.

**Export scans skip build output and survive a vanishing path.** The export
self-sufficiency scan prunes `target/`, `node_modules/`, `__pycache__/`, and
`.git/`, and a file that disappears between listing and stat is skipped rather
than raised; the pre-push lane runs `check-rust` beside this scan and had
tripped on a compiler temp file.

**Release critique repairs, in this tree.** The docs-length record whose map has
emptied stays a ratchet: an existing record with an empty map is no longer
re-founded by the writer, and an absent record is founded from the tree; the
mechanisms table distinguishes an archive event from a graduation; the ordinary
implementation sequence names one commit order; and the shared graduation
reference addresses the lifecycle helper through the checkable plugin
placeholder.

**Smaller surfaces, same rules.** The retro skill is back under its core
budget with the same bootstrap, workflow, and persistence steps; the generated
CLI reference preamble states the payload contract once and links its owner;
quality-gate timing labels drop their dates.
