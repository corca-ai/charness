## Fixes

The `handoff` chunked-routing auto-draft no longer asserts a moved-away path as
the work surface. When the chunker finds a cited path missing, a cited issue
closed, or the tracker unable to answer, the drafted goal artifact now carries
that inline (`MISSING` / `CLOSED` / `UNRESOLVED`), and keeps missing paths out
of `Boundaries -> In scope:` under a separate `NOT asserted in scope:` bullet.
The achieve Before-phase re-targets instead of planning against a dead
reference.

## Read markers as positive findings only

An **unmarked** citation means clean **or** never checked — it is not a
freshness guarantee. Path existence is checked whenever the chunker resolves a
repo root; issue state is checked only when you pass `--with-issues`. The
drafter cannot yet see which checks ran, so it never renders "checked and
clean" either.

## Scope

No migration, no config change, and no behavior change outside the
chunked-routing auto-draft. Existing goal artifacts are untouched — the drafter
renders at draft time only and refuses to overwrite an existing artifact.
