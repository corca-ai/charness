# Charness v1.0.3

Charness v1.0.3 fixes the quality artifact scaffold so its generated Runtime
Signals citation is durable by construction.

## What Changed

- The canonical quality scaffold now marks the gitignored runtime metrics path
  as a same-line reproduction source.
- A focused regression freezes the generated marker/path relationship.
- Source and installed plugin scaffold implementations remain identical.

## Why

A quality record created from the canonical scaffold could pass its shape
validator and later fail the final evidence-durability gate. The producer now
emits the consumer's existing grammar instead of relying on hand correction.

## Update

```bash
charness update
```

Then restart active Claude Code and Codex sessions if cache rotation is
reported, and verify with `charness doctor` and `charness --version`.

## Verification

Focused scaffold tests, evidence-durability validation, plugin parity,
packaging, public quality-skill validation, and the final release gate pass on
the exact release bytes.

No durability-validator behavior, broader ignored-path grammar, Cautilus
evaluation, or issue lifecycle changed in this patch.

## Rollback

Reinstall v1.0.2 if necessary. Do not delete or repoint published tags; use a
corrective release for publication problems.
