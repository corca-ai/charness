# Charness v0.63.1

This patch release tightens proof honesty and maintenance ergonomics for
prompt-mutation and quality workflows.

## What Changed

- Prompt-mutation marker scoring now treats only Bash command-bearing stream
  records as command execution evidence. Prose, paths, task text, and non-Bash
  tool input no longer count as executed commands.
- Skill-efficiency A/B validation now rejects invalid spend/config inputs before
  runs, reducing wasted evaluator or experiment time.
- Quality standing-test economics now separates standing, mixed, and
  release-only nested CLI cost more honestly.
- Markdown preview support has safer path handling and clearer CLI help.
- The debug planner now explains `--repo-root` in `--help` output.

## Upgrade

- No migration is required.
- Run `charness update` to install the latest published release.
- Restart active Claude/Codex sessions if the update reports cache path or
  session staleness.

## Non-Claims

- This release does not change public prompt prose.
- The scoring repair narrows one evidence channel; it is not a claim that every
  proof-capture path is now complete.
- Broader CLI help debt remains and will continue to be reduced in smaller
  follow-up slices.
