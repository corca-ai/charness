# charness v0.59.0

## Scope

One consumer-visible behavior change — **Slack/Notion `gather` is now
credentialless by default** — plus internal quality hardening (reference
compaction, test-value audit, scaffold/eval-floor internals). No operator-typed
command, flag, doctor output, or install step changed by the internal work.

## Behavior change — read this if you use `gather` for Slack or Notion

An installed `gather` skill **no longer advertises a provider-CLI route for Slack
or Notion by default.** With no adapter, both now resolve to provider mode `none`
and stop with a missing-capability explanation instead of pointing at the
charness-owned provider wrapper. This closes a boundary gap where a consuming repo
kept discovering credentialed provider routes it had not authorized (#417).

**If you relied on no-adapter Slack/Notion `gather`, re-enable it** by adding to
`.agents/gather-adapter.yaml`:

```yaml
gather_provider:
  slack:
    mode: direct-cli      # maintainer owns the grant
    # or: host-mediated   # route via the runtime's own Slack capability
  notion:
    mode: direct-cli
```

`github` and `google_workspace` defaults are **unchanged** (`direct-cli`; Google
Workspace has no repo-owned CLI and still routes to a host-mediated capability,
an operator export, or a browser-mediated fallback). Credentialless public and
local gather is unaffected.

## Changes

- **gather credentialless-by-default (#417).** Plain gather targets public/local
  sources; credentialed org access (Slack/Notion) is an explicit adapter opt-in
  described as a host/runtime-owned capability, not a charness-prescribed provider
  CLI. Support runtimes are kept (reversible), just no longer the default route.
- **Reference compaction (slices 1–6).** Advisory `classTag` annotations, RCF-or-RSF
  floor guard, and headroom-exempt `## Closeout Vocabulary` refinements. No
  consumer-facing reference docs were deleted (the delete track found 0/17 safe).
- **Test-value audit.** ~23 zero-kill-value tests and 2 dead source functions
  removed; coverage preserved. Internal only.

## Behavior notes

- The only consumer-observable behavior shift is the Slack/Notion `gather` default
  above.
- **Internal:** the artifact scaffold helpers (`scaffold_*_artifact.py`) now always
  emit their JSON payload; the `--json` flag was removed. These are skill-execution
  helpers, not operator-typed commands — public skill behavior is unchanged. If you
  invoke these scripts directly in your own automation, drop `--json`.

## Install

- Run `charness update` to install v0.59.0, then `charness doctor` to confirm no
  version skew.
- Read this release note for the gather default change before upgrading Slack/Notion
  gather workflows.
