# Charness v8.14.7

## What changed

- Task-run and bounded-review outcomes now derive delivery, identity, and completion state from retained evidence and their canonical runtime owners.
- `task status --all-repos` exposes aggregate managed-task inventory, and task self-review runs when `--self-review` is explicitly requested.
- Retained review attempts created before an update fail closed when their boundary mode cannot be proven. Rerun the bounded review after updating instead of restoring legacy inference.
- The persistence-risk guard continues to require review when candidate content contains `DROP`, `TRUNCATE`, or an unscoped `DELETE`, so a `completed-needs-review` result can reflect that content risk.

## Update

Run `charness update`, then use `charness version` to read back the installed version. No migration is required.
