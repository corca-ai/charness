# charness v0.61.0

## What changes for you

After you run `charness update` and restart your sessions, **session start no
longer invokes `find-skills` on every session.** The session-start hook now
front-loads the routing decision directly into its injected directive with three
branches:

- **pickup** (session start with no explicit task) → the `handoff` workflow;
- **capability discovery** ("which skill handles X?") → `find-skills`;
- **any other task** → the durable work skill that best matches, with
  `find-skills` invoked only when the capability map is missing/stale or the
  route is genuinely unclear.

Nothing you type changes: no command, flag, `doctor` output, or install step
moved, and there is **no migration**. The only action is to restart open
sessions after updating so they pick up the new routing. The change is
**reversible and opt-in** — the session-start hook is adapter-gated and has
uninstall paths if you prefer the old every-session behavior.

## Changes

- **Session-start front-load (routing in the hook).** The session-start
  directive now carries the full 3-branch routing instead of mandating a
  `find-skills` invocation every session. #240 routing protections
  (pickup→handoff, discovery ownership, "drive the routed workflow") are carried
  over into the shipped directive and locked by
  `tests/test_session_start_find_skills.py`.
- **`achieve` phase-brief demote.** `check_goal_artifact.py` now emits an
  advisory `phase_brief` (new `goal_artifact_phase_brief.py`) that routes a run
  to the current-phase lifecycle/goal-artifact sections instead of always
  loading the full 52KB+ lifecycle doc. An A/B check (n=3/arm, judge-graded)
  found **judged outcome parity both arms** and converted silent
  non-compliance (pre: 0/3 runs opened the lifecycle doc) into cheap
  phase-scoped section reads (post: 3/3). This is a behavioral-compliance
  change with no measured outcome regression — it is **not** a
  token/context-reduction claim (the total-token A/B delta is inconclusive at
  n=3).
- **`quality` inventory-dispatch demote.** The quality inventory dispatch moves
  to on-demand (`catalog.yaml`, `plan_quality_run.py`), briefing the routing
  index instead of an always-load.
- **Reference-compaction.** Docs/reference rationale audit and skill anatomy map
  across skills; tests and cautilus claim-fidelity specs updated to match.

## Bump rationale (MINOR, not PATCH)

Per `version-policy.md` this is a judgment call. The release is
efficiency/compaction-heavy and internal, but it ships **new adoptable
behavior** — the session-start routing front-load changes how every session
opens for installed operators, which they adopt by updating without any
migration. That makes MINOR (0.60.0 → 0.61.0) more honest than PATCH, which is
reserved for behavior repairs that preserve the same public shape.

## Install

- Run `charness update` to install v0.61.0, then `charness doctor` to confirm no
  version skew.
- Restart open sessions after updating so the new session-start routing takes
  effect. No migration required.
