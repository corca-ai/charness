compatibility around the current issue-backlog closeout. The production fixes
for earlier issues remain attributed to the commits in which they landed.

- Restored compatibility with Cautilus 0.19.3 by using supported proposal
  evidence kinds and explicitly selecting JSON for parsed command output.
- Added regression tests for both Cautilus command boundaries.
- Split three large test matrices into focused modules, reducing Python length
  advisories without changing production behavior or assertions.

  exemptions for the moved subprocess tests.
