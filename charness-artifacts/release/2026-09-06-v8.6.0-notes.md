# Charness 8.6.0

## Changes

Start issue-resolution reviews through the issue skill’s `review-resolution` command, which supplies the intended review purpose and issue targets.

Before a reviewer starts, the command checks citations in selected artifact documents against the existing durability rules and exemptions, without scanning unrelated documents. This checks readiness, not approval; final closeout checks remain in place.

See the [issue review instructions](https://github.com/corca-ai/charness/blob/v8.6.0/skills/public/issue/references/closeout-discipline.md#bundled-closeout) for usage.

## Compatibility and limits

These checks target Git repositories. Non-Git fallbacks are removed; alternate Git and provider access paths remain unchanged.

Regression fixtures demonstrate fewer avoidable review launches. Live end-to-end time and token savings remain unproven.

## Update

Run `charness update`, then inspect the installed state with `charness version` and `charness doctor`.
