# Charness 8.5.0

## Changes

- Finish related issues with a current shared review and per-issue bug/feature
  classification, without commissioning another review just to reformat evidence.
- Release preparation defers the semantic subject suite to the final,
  claims-bound resume. Current publication checks remain required; this is
  scheduling, not a cross-commit test cache.
- Spec, debug and retro guidance can reuse applicable known context. Missing or
  changed context, uncertain causes and recurrence keep their diagnostic routes.

## Observed limits

The delegation pilot did not establish an efficiency gain. The valid higher-tier
candidate completed correctly but cost more; the lower-tier comparison had
preservation failures and an unfrozen installed-helper dependency. Original
results and limitations remain in the
[comparison record](https://github.com/corca-ai/charness/blob/main/charness-artifacts/probe/2026-09-06-delegation-net-value/results.md).

## Update

Run `charness update`, then `charness version` and `charness doctor` to inspect
your installation. No configuration migration is required.
