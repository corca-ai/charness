## 목표 요약

스카우팅 결과 `scripts/`에는 파이썬 파일 270개(그중 argparse CLI 엔트리포인트 144개)가 있고, 78개가 이미 각자 방식의 `--json`을 갖고 있으며 공유 헬퍼는 없습니다. 목표는:

- **Slice 1** — `scripts/json_output_lib.py` 공유 헬퍼 + 계약을 정의하는 단위 테스트 (플래그 등록, stdout에 JSON 문서 정확히 1개, 결정적 직렬화, 구조화된 에러 페이로드 + 종료 코드).
- **Slice 2** — 전체 144개 엔트리포인트로 시드한 축소-전용 베이스라인 컨포먼스 게이트(기존 boundary-bypass 래칫 패턴 재사용) + 신규 스크립트/rename/exemption 정책.
- **Slice 3** — 대표 스크립트 ~8개 파일럿 마이그레이션.
- **Slice 4+** — 소비자-리스크 순서의 배치 마이그레이션(훅이 소비하는 스크립트는 마지막), 베이스라인이 단조 감소.

핵심 경계: 헬퍼는 **메커니즘만** 표준화하고 기존 78개 스크립트의 페이로드 스키마는 절대 바꾸지 않습니다(테스트·게이트·`.githooks/pre-push` 같은 소비자가 형태를 고정하고 있음).
