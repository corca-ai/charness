### Replacement control

**None, deliberately.** The commit is explicit: "Removed rather than deprecated —
no disabled shell, no lighter gate in its place."

The honest reading of the two tables: the removed mechanism verified
install/host-mutation behavior on a real host BEFORE publish. The retained
`post_publish_*` readbacks exercise install behavior AFTER publish. So the axis
is not wholly unguarded, but the guard moved from pre-publish to post-publish —
it can now detect a bad install rather than prevent publishing one. A reviewer
judging this removal should judge that trade, not the deletion count.
