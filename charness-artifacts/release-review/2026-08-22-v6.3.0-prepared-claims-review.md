## Why Four Rounds Did Not Converge

Every round confirmed the shipped CODE was clean — the quality-status owner
mechanism, all five version surfaces, and every derived figure reconciled in
each round that checked them. Every blocker was prose *about the review*.

The bundle contains the artifacts that describe the review. So repairing a
finding changes the bundle, which changes the record, the path count and the
blocker totals, which requires new prose that nothing has reviewed. Repairing is
what generates the next round's findings. Filed as **#701**.
