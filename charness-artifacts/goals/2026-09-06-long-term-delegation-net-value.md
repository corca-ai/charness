# Achieve Goal: Make long-term delegation cheaper without weakening completion or recovery

Created: 2026-09-06
Planning record: mutable until Goal Binding; the binding freezes these exact bytes.

## Goal

Improve Charness for the operator's confirmed purpose: delegating long-running work. Remove demonstrated duplicate review packaging, repeated semantic verification, and unconditional rediscovery while preserving intent, resumability, per-item behavioral proof, and authority boundaries. Evaluate candidate versus no plugin separately at high and low model tiers on comparable multi-stage delegation tasks; report actual usefulness and limits, not a presumed win.

  evidence rewriting, or organization-wide external writes.

## Agent Verification Plan

### Low-Cost Checks

- Reproduce scalar-target/global-classification failures before repair; exercise
  exact-set and missing/extra/swapped/foreign/duplicate-target negative controls.
- Freeze release equivalence before coding: semantic source, verifier/config,
  dependencies/runtime, materialized package, allowed claims-only delta, command
  scope and proof provenance. Reject absent/stale/untrusted receipts and test
  both eligible resume and invalidation through the actual final consumer.
- Test changed/unchanged/missing context and obvious/uncertain/recurring causes
  through consuming entry paths. Keep parsed schema/frontmatter/form checks;
  remove wording pins only where the real capability has another owner.
- Run cheap affected-owner checks after edits, before the next broad lane.

### High-Confidence Checks

- Two framing/ownership lenses, executable children, then adversarial whole-plan
  critique. Material risk drives implementation review, not commit count.
- Before/after command and input identities establish removed work; wall time
  and artifact count alone prove neither redundancy nor consumer value.
- Count replacement cost too: receipt production/validation, invalidation,
  fallback and added review. Keep an existing operation if its replacement
  costs more without a compensating capability gain.
- Freeze fixtures, cooperative stop point, handoff powers, intervention rubric,
  budgets and hidden acceptance before any arm. Evaluate actual output separately
  from producer summaries. Hide oracle and other-arm outputs from all producers.
- Candidate/no-plugin is the product comparison; 8.4.4 mechanism regression is
  the removal/equality comparison. Keep those evidence classes separate.
- Freeze candidate revision before candidate execution. Preserve the original
  four-arm results; a repair and rerun is separately labelled, never substituted
  into the initial comparison. Any revised oracle invalidates the old comparison.
- Authoring integration retains standing then full read-only. Changed-line,
  verdict and release proof follow the current boundary owner; reviewed equality
  must justify a removed execution, not a skipped-gate green.

### External or Live Proof

- One bounded 2x2 pilot: candidate/no-plugin crossed with high/low model tiers.
  Reuse alias fixture semantics, not plugin-contaminated seed instructions.
  Exact model IDs, effort, budgets and arm order are frozen before execution.
- Same neutral host execution, seed, semantic goal, issue powers, network and
  sandbox per arm. No-plugin excludes Charness instructions/helpers/metadata,
  but retains ordinary documentation, tests, notes and normal host abilities.
- Stop after a cooperative checkpoint; deliver the same predeclared contract
  delta durably; resume in a fresh context without repeating old task context.
  The hidden oracle checks original behavior, delta behavior and state safety.
- Report phase/total time, tokens when exposed, cost only with a sourced price
  snapshot, rescue/clarification interventions excluding scheduled events,
  repeated unchanged-input work and correct first action after resume.
- A neutral external harness may isolate fixtures and collect logs; it must not
  perform producer planning, checkpoint recovery or task repair for either arm.
  Do not install a new product runner. Disclose unavailable cells and deviations.
- Non-claims: arbitrary crash recovery, general long-goal reliability, statistical
  superiority, other hosts or unrelated workloads from one four-arm pilot.
- Publication uses release-owned proof/readback. Public artifact existence,
  installed behavior and tracker closure are distinct claims.
