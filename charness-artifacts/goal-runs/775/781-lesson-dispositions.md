Operator rule, settled on lesson 2 and applied to every lesson from then on
(and retroactively to lesson 1): **graduation is three questions, not one.**
(1) Which single `docs/` page owns the rule, and which duplicates elsewhere are
removed or replaced by a link. (2) Can the rule be enforced in code (a gate, a
runner preamble, a refusal) so the doc sentence describes a mechanism rather
than asking to be remembered; if yes, the mechanism ships in the graduation
commit and the docs sentence names it. (3) Only then the lifecycle event. The
promotion skill must carry this rule (see follow-up below).

Second operator rule, settled after lesson 4 ("why is everything graduating?"):
a graduation with NO mechanism is allowed only when the owning page is read at
the decision moment the class arises; otherwise the lesson stays active, since
the preview is read every session and a docs page only on demand. Written into
`lesson-graduation.md` question 2.
