questions under an adapter-controlled ceiling, then recover an approved Goal

  recommendation, reason, answer, and rejected alternatives.
- Resolve `/goal #N` against the current repository, read the parent and binding,

  permits it; the bootstrap marker is not target-runtime readiness.

child, clean-process pickup, and compatibility tests through the repo-owned
standing runner. Prove that `/goal #725` is refused because a child is not a

or mutate installed host state. The target `/goal #724` pickup roundtrip is
verified in a clean Python process; that proves the local/provider read path,
