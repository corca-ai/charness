## Critical Decisions

- **Seeding and appending are one command.** The ledger has no separate
  "add a lesson later" operation, so a bootstrap-only seeder would have closed
  the cold start and left the identical hole open for every lesson authored
  afterwards. The repo was already in that state: 16 seeded, 15 stranded.
- **No automatic archive, against #626's stated expected behavior.** The spec's
  early text calls archive automatic; its Eighth Slice supersedes that and says
  the positive-only cohort cannot justify a threshold. Every lifecycle event
  requires a reviewed `decision_ref` an automatic run would have to fabricate.
  Recorded in the code, not just decided.
- **The lifecycle review orders by anchors, not recurrence.** Verified against
  live data rather than asserted: `premise-not-checked-against-source` leads on
  8 independent sources with zero anchored evidence, so it lands in the
  undetermined group instead of at the top of a graduation proposal.
- **The handoff's own item 2 is unexecutable and was reported rather than
  forced.** The 2026-08-14 session declared no lesson session, so scoring "the
  previous session's miss" would require citing a different session's frozen
  list -- the backfill the observability contract names and forbids.
- **A test-scoped exemption over a file-scoped one.** `ALLOWED_FILES` would have
  disarmed three unrelated checks over every test in the file, permanently.

## North Star Alignment

The north star asks for a briefed judge with teeth only where a wrong answer
escapes. Both halves showed up.

Held: the lifecycle review is a briefing surface with an explicit non-verdict and
an always-zero-on-validatable-ledger exit, and the three dispositions are named
for a human rather than computed by a classifier the spec forbids. The
solicitation is a brief, not a gate. Teeth stayed with the existing validators.

Mis-applied: the exemption bar ("observes something no standing gate otherwise
observes, and the cost is measured") was written as a comment guarding a proof
surface -- the prose ritual the north star deprioritizes -- and only became
executable after a reviewer said so. It is now a required dict value checked for
a figure and a time unit.

Failure signature walked into: **declaration is not corroboration**, on my own
work. `_provenance.baseline_check` claimed the gate pins "every residual figure"
while the gate compared four; the field this very refresh moved was unpinned.
That is the exact class the file it lives beside is named for.

## Expert Counterfactuals

Engelbart (system-improving-itself), the planner's fitted lens: treat H + LAM + T
as one unit. Applied to #627, the tool (T) shipped -- a solicitation the planner
emits -- but the language (LAM) shipped with it made a causal promise the tool
does not keep. The lens would have asked what the tool DOES before writing what
it means, which is the same question `recent_lessons_lib` answers in one grep.

Direct counterfactual, stronger here: for every mechanism claim written into an
emitted surface, open the mechanism. Three of the four review blockers were
claims about behavior (`run_when` gating, exit codes, score-to-wording) that a
single read would have refuted. That is `premise-not-checked-against-source`
firing at session start and not transferring to in-flight assertions -- the
form-not-transferring problem #627 was filed about, observed on #627's own slice.
